# Overview

This was a project where I wanted to understand making modular systems within video game development. I also wanted to learn more about pygame and how it's classes and methods worked. So I tried making a two player game of Pong developed with the modular system I wanted to develop. Part of this project also helped me understand events and key-bindings.

It's a simple two player game of Pong. You play the game by having each player take control of their paddle and return the pong ball back to the other player, you score by getting the ball past the screen of the players side of the board. You return the ball by having your paddle run into the paddle. Player #1 controls their paddle using the "A" and "D" keys, Player #2 controls their paddle using the left and right arrow keys.
